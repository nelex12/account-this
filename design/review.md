## 2. Модели и перечисления

- **Tool** — все 8 полей: номер, название, состояние, комментарий, `isActive` (списан), держатель, ФИО держателя, «с какого времени».
- **RentalLogEntry** — все 12 полей видны в разборе записи (`24`): id, инструмент, сотрудник, завхоз, действие, заявленное состояние,
  три метки времени с разницей «+95 с». Для `toolId`/`workerId = null` имя взято из QR и помечено курсивом со «?».
- **UserResponse** — ФИО, телефон в формате `+7 (XXX) XXX-XX-XX`, роль, статус из пары `isApproved`/`isActive` (4 комбинации).
- **Перечисления** — каждое значение `UserRole`, `ToolCondition`, `RentalAction`, `ValidationFlag` имеет подпись, цвет и иконку
  (таблица в `01-design-system`) и объяснение простыми словами; на досках журнала и проверки показаны разборы `TIME_DRIFT` и `INVALID_SERVER_SIG`, в обзоре — `DUPLICATE` и `INVALID_WORKER_SIG`.

## 3. Правила из описания проекта

| Правило | Как отражено |
|---|---|
| Сертификат 12 часов, выдаётся онлайн | Время до конца и полоса остатка; без сети получить нельзя (`05`) |
| Окно 60 секунд | Таймер на QR-коде (`07`), отказ «QR-код устарел» (`13`) |
| Порядок оффлайн-проверок | Список из 6 проверок в том же порядке; первая непройденная останавливает остальные (`13`) |
| Расхождения с реестром — не блокируют | Предупреждения + отметка об осмотре (`12`) |
| Заявленное состояние — подписанное заявление | Подсказка на экране операции; при возврате состояние не выбрано заранее (`07`) |
| Держатель — только по синхронизированным записям | Пояснение под реестром; неотправленные операции устройства отмечены отдельно (`15`) |
| «Кто сломал» — по журналу | Блок «Повреждения при возврате» (`26`), отметка в истории инструмента (`19`) |
| Ручной PATCH выставляет время изменения | Пояснение в диалоге изменения состояния (`21`) |
| Списание необратимо, только Owner | Зона списания только у владельца, диалог с последствиями (`20`) |
| Нельзя уволить себя | Своя строка помечена «Это вы», кнопки нет (`28`) |
| Нет отзыва JWT и сертификатов | Сказано в диалоге увольнения: доступ действует до 12 часов (`29`) |
| Телефон уникален, включая уволенных | Ошибка 409 (`04`), пояснения во вкладке «Уволены» и в диалогах (`28`, `29`) |
| Время — по часам сервера | Поправка часов у сотрудника и завхоза (`05`, `08`) |
| Повторная отправка идемпотентна | Кнопка «Отправить» безопасно повторяется; отложенные записи не блокируют остальные (`14`) |

## 4. Визуальная проверка PNG

Каждая доска снята, просмотрена целиком и по фрагментам. Найдено и исправлено:

| Что было | Исправление |
|---|---|
| Наклейка: размеры внутри считались от ширины экрана, номер вылезал за край | Наклейка стала отдельным контейнером, всё внутри — от её ширины |
| Номер на термонаклейке 58×40 обрезался | Уменьшен кегль для этого формата |
| В карточках выбора заголовок и описание слипались в строку | Разнесены на две строки |
| Экран проверки: название инструмента переносилось рядом с номером | Название сверху, номер и данные реестра строкой ниже |
| Экран проверки с предупреждением: отметка «осмотрел» уходила под кнопки | Сокращены тексты, время QR перенесено в зелёную строку |
| Вариант «уже на месте»: строка «в реестре: на руках» противоречила предупреждению | Показываются данные устройства: «возвращён в 13:58» |
| Отказ в проверке: список проверок был ниже экрана | Список проверок поднят над деталями |
| Записи смены: название обрезалось до «Гайковёр…» из‑за чипа статуса | Статус перенесён на отдельную строку |
| На плитках стенда «Повреждён» вылезал за край, чипы растягивались | Чип перенесён вниз плитки, выравнивание по левому краю |
| Счётчик «7» на вкладке «Смена» после отправки | Счётчик берётся из состояния экрана |
| Подсказка графика перекрывала легенду | Подсказка справа от столбца |
| Телефон и маска разрывались переносом | Запрещён перенос в номерах и масках |
| Подсказка на экране операции обрезалась кнопкой | Перенесена под заголовок блока |
| Длинные экраны обрезались рамкой (карточка, печать, обзор) | Сняты целиком |

Итог последнего экспорта: 34 PNG, ошибок на странице нет, все три шрифта загружены.

## 5. Контраст

Посчитан по формуле WCAG для ключевых пар (светлая / тёмная тема):
основной и приглушённый текст на фоне — не ниже 4.5:1 (приглушённый: 4.8 / 5.7);
текст чипов на их подложке — 5.7–9.6; белый текст на синей кнопке — 7.7 / 5.3, на красной — 5.7 / 4.8.
Палитра графика проверена валидатором: пары «требует проверки / подозрительно» различимы при дальтонизме (ΔE 9.6),
все цвета отметок контрастнее 3:1 к фону.

## 6. Что осталось за рамками

- QR-коды — имитация узора, не настоящие коды.
- На телефонных макетах часть длинных экранов показана до места прокрутки; самые длинные сняты целиком.
- Нет макетов установки приложения на телефон (PWA) и печатной формы отчётов — в описании проекта их нет.
- Замечания к контракту и открытые вопросы вынесены в `api-notes.md`.
